Advanced Underwater Image
Enhancement & Detection

A full computer vision pipeline tackling the unique physics of underwater light propagation — combining physics-based image restoration with a high-accuracy deep learning detection stack, achieving 96.46% accuracy.

  • Multi-stage enhancement: Fourier frequency filtering → Dark Channel Prior dehazing → Laplace decomposition for detail recovery

  • End-to-end pipeline from raw degraded frame to classified detection output

P_03 COMPLETED May 2025

Morse Code Generator
on LPC2148 ARM7

A precise embedded system translating alphanumeric input into standardised Morse code — with real-time 16×2 LCD visual feedback and hardware-accurate tone generation using Timer0 configuration.

  • Implemented on LPC2148 (ARM7TDMI-S) with UART-based serial input at configurable baud rates
  • Lookup table architecture for O(1) character-to-Morse translation with full ASCII coverage
  • Timer0 configured for precise 1 kHz carrier with standardised timings: 100ms dot, 300ms dash
  • Programmed in Embedded C using Keil µVision IDE; simulated and verified in Proteus
